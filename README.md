# 수업 캘린더 (PWA)

트레이너 업무용 개인 스케줄 앱입니다. 폰 홈 화면에 앱처럼 설치해서 쓰고, 인터넷이 없어도 열립니다.
일정은 폰(브라우저) 안에 저장됩니다. 서버나 회원가입은 없습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 스타일, 동작 코드) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 실행 방식 (설치에 필요) |
| `sw.js` | 오프라인 실행을 위한 서비스 워커 |
| `icons/` | 앱 아이콘 |
| `CLAUDE.md` | Claude Code가 프로젝트를 이해하는 데 쓰는 메모 |

## 1. 내 맥에서 먼저 열어 보기 (VS Code)

1. VS Code에서 `File > Open Folder`로 이 폴더를 엽니다.
2. VS Code 터미널(`` Ctrl+` ``)에서 아래 중 하나를 실행합니다.
   ```bash
   python3 -m http.server 8080
   # 또는
   npx serve .
   ```
3. 브라우저에서 `http://localhost:8080`을 엽니다.

`index.html`을 더블클릭해서 여는 방식은 서비스 워커가 동작하지 않아 설치 기능을 확인할 수 없어요. 꼭 서버로 여세요.

## 2. 폰에 설치하려면 인터넷 주소(HTTPS)가 필요해요

PWA 설치는 `https://` 주소에서만 됩니다(맥의 `localhost`는 예외). 무료 호스팅 중 하나에 올리세요.

### 방법 A. Vercel (추천)

```bash
npm i -g vercel
vercel        # 처음이면 로그인, 나머지는 Enter로 진행
vercel --prod
```

프레임워크를 묻는 질문에는 `Other`, 빌드 명령과 출력 폴더는 비워 두면 됩니다.
끝나면 `https://프로젝트이름.vercel.app` 주소가 나옵니다.

### 방법 B. GitHub Pages

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 `Settings > Pages`에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`를 고릅니다.
3. `https://내아이디.github.io/저장소이름/` 주소가 생깁니다.

수업 데이터는 코드와 따로 폰에만 저장되니, 주소가 공개돼도 일정 내용이 노출되지는 않아요.

## 3. 폰에 설치

- **아이폰**: Safari로 주소를 열고 공유 버튼, `홈 화면에 추가`를 누릅니다. (Safari에서만 설치돼요.)
- **안드로이드**: Chrome으로 주소를 열고 메뉴(점 세 개), `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

설치한 뒤에는 홈 화면 아이콘으로 실행하세요. 브라우저 탭에서 쓰던 일정과 설치한 앱의 일정은 저장 공간이 따로일 수 있어서, 설치 후에 일정을 입력하는 편이 안전해요.

## 데이터 백업 (중요)

일정은 폰 브라우저 저장소에 있어서, 앱을 삭제하거나 브라우저 데이터를 지우면 함께 사라져요.
화면 위쪽 `백업·복원`에서 백업 파일(.json)을 가끔 내보내 두세요. 폰을 바꿀 때도 같은 화면에서 복원하면 됩니다.

## 코드를 고친 뒤 배포할 때

`index.html` 등을 바꿨다면 `sw.js` 맨 위의 `CACHE` 이름 숫자를 올리세요(예: `lesson-calendar-v2`). 그래야 폰이 새 버전을 받아 갑니다. 그 뒤 `vercel --prod`로 다시 배포합니다.

## Claude Code로 이어서 개발하기

```bash
cd 이 폴더
claude
```

프로젝트 설명은 `CLAUDE.md`에 들어 있어서 따로 설명하지 않아도 됩니다. 이렇게 요청해 보세요.

- "회원별로 수업 회차(예: 10회 중 3회차)를 관리하고 싶어"
- "사인지 기본 양식을 이미지로 줄게. 회원·날짜·시간이 채워진 화면을 만들고 인쇄할 수 있게 해줘"
- "수업 시작 30분 전 알림을 넣을 수 있는지 알려줘"
